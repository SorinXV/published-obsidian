## Obsidian Extensions

- **Advanced Tables**: Adds spreadsheet-like features to Markdown tables, including automatic formatting, navigation via `Tab`/`Enter, and formula support.
    
      
    
- **Automatic Table of Contents**: Generates and dynamically updates a table of contents within your notes based on your document headings.
    
      
    
- **Better Export PDF**: Enhances Obsidian's native PDF export tool by adding customizable headers, footers, page breaks, and display options
    
      
    
- **Calendar**: Displays a sidebar calendar widget that integrates seamlessly with your daily, weekly, or periodic notes.
    
      
    
- **Code Styler**: Customizes the appearance of code blocks and inline code, adding features like line numbering, active line highlighting, and titles.
    
      
    
- **Colored Tags**: Adds custom colors and styling to tags in your vault to improve visual organization and scannability.
    
      
    
- **Desmos**: Embeds interactive Desmos graphing calculators directly inside your notes for visual math plotting.
    
      
    
- **Editing Toolbar**: Adds a visual formatting bar at the top of your editor for quick access to bold, italics, highlights, text alignment, and other markdown controls.
    
      
    
- **Execute Code**: Runs code snippets directly within your notes across various programming languages (e.g., Python, JavaScript, C++).
    
      
    
- **File Explorer++**: Enhances the default file explorer by adding extra features like folder pinning, custom sorting, and file filtering.
    
      
    
- **Git**: Automatically backs up, commits, and syncs your Obsidian vault to a remote GitHub or GitLab repository.
    
      
    
- **Highlightr**: Makes text highlighting faster and more customizable by offering a color palette pop-up when text is selected.
    
      
    
- **Iconize**: Allows you to add custom icons to files, folders, and navigation items throughout your vault's file tree.
    
      
    
- **Importer**: Converts files exported from other note-taking applications (like Notion, Evernote, or Apple Notes) into standard Markdown notes.
    
      
    
- **Lazy Loader**: Improves Obsidian startup times by deferring the loading of selected heavy plugins until they are actually needed.
    
      
    
- **Mathpad**: Provides an interactive scratchpad environment for solving math equations and rendering step-by-step calculations.
    
      
    
- **Mind Map**: Converts the heading hierarchy and bulleted lists of your active note into an interactive visual mind map.
    
      
    
- **Omnisearch**: A fast, fuzzy search engine for your vault that searches through Markdown files, PDFs, OCR images, and canvas files.
    
      
    
- **Peerdraft**: Enables peer-to-peer real-time collaboration on notes directly with other users without relying on a central cloud service.
    
      
    
- **Pretty Properties**: Enhances the visual presentation and layout of note frontmatter/properties tags.
    
      
    
- **Solve**: Automatically calculates inline math equations and expressions directly as you type them in your notes.
    
      
    
- **Tasks**: Adds advanced task management capabilities, allowing you to set due dates, recurring tasks, priorities, and filter tasks across your vault.
    
      
    
- **Templater**: A powerful scripting engine that lets you insert dynamic templates, code snippets, and automated logic into your notes.
    
      
    
- **Various Complements**: Adds an inline auto-completion pop-up as you type, suggesting matching words, internal note links, and tags.
    
      
    
- **Webpage HTML Export**: Exports individual Markdown notes or entire vaults into fully functional HTML files/websites with preserved styling and links.
